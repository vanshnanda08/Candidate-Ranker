# Instrument typefaces

Unmodified font files, self-hosted for offline dashboard use:

- Instrument Sans variable upright: https://github.com/google/fonts/tree/main/ofl/instrumentsans
- Instrument Serif regular upright: https://github.com/google/fonts/tree/main/ofl/instrumentserif

Downloaded 2026-11-14 from the Google Fonts repository. Each family includes its original SIL Open Font License notice alongside the font. No remote font requests are made by the app.
